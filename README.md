# 🍫 Awesome Chocolates Sales Analytics Dashboard

An interactive **Power BI dashboard** built to analyze the sales performance of Awesome Chocolates. The dashboard enables users to explore business performance through dynamic navigation, KPIs, and interactive visualizations for better decision-making.

## 📌 Project Overview

This dashboard provides a comprehensive view of business performance by tracking:

- Sales
- Profit
- Costs
- Shipments
- Boxes Sold
- Product Performance
- Salesperson Performance

The report is fully interactive, allowing users to switch between different business metrics and filter data instantly.

---

## 🎯 Business Objectives

- Monitor overall sales performance.
- Analyze monthly sales trends.
- Identify top-performing products.
- Evaluate salesperson performance.
- Track shipment distribution.
- Measure profitability using KPIs.
- Compare business performance across countries and product categories.

## ✨ Dashboard Features

### 📊 KPI Cards

- Total Sales
- Total Boxes
- Total Shipments
- Total Costs
- Total Profit
- Overall Profit Percentage Gauge

---

### 📈 Interactive Navigation

Users can switch between multiple dashboard views:

- Sales
- Boxes
- Shipments
- Profit
- Costs

Each view dynamically updates the charts and tables.

---

### 📉 Visualizations

- Monthly Sales Trend
- Shipment Distribution (Histogram)
- Product Performance Table
- Salesperson Performance Table
- Profit Percentage Bars
- Shipment KPI Gauge
- Performance Status Indicators

---

### 🎛 Interactive Filters

#### Product Categories

- Bars
- Bites
- Other

#### Countries

- Australia
- Canada
- India
- New Zealand
- UK
- USA

Selecting any filter instantly updates all visuals on the report.
